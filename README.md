# 阿拉丁 GenieBox (Aladdin GenieBox)

把回憶，放回掌心。

阿拉丁 GenieBox 是一款面向 **Amlogic S905X5M Android TV Box 與 Android 手機**的開源復古遊戲 App。從自己的遊戲資料夾建立收藏庫，透過封面、平台分類與搜尋，找到下一款想玩的遊戲。

模擬核心整合於單一 APK，不必另外安裝 RetroArch、PPSSPP 等 App。ROM 可從手機本機資料夾、USB 隨身碟或 SD 卡讀取，存檔與設定預設保存在裝置內部空間。

### 純淨，專注遊戲

- **語言與外觀可自選**：介面預設繁體中文，可切換簡體中文與英文；外觀提供淺色、深色與跟隨系統，並記住選擇。可從「設定 → 語言與外觀」調整。
- **無廣告、無內購、無須登入**：不以開屏廣告或促銷打斷遊玩。
- **離線使用**：使用者準備好遊戲檔案後，即可在本機整理與遊玩，不提供 ROM 下載或內建遊戲商店。
- **手機與電視各有合適的操作**：手機提供觸控、直橫向版面與虛擬手把；TV 提供焦點導航與實體手把操作。
- **自己的遊戲收藏庫**：平台分類、中文／拼音／注音搜尋、收藏、最近遊玩與本機封面配對。可自訂顯示名稱與封面，並記住分類、搜尋、排序、捲動位置及 TV 焦點。
- **保留遊戲進度**：提供即時存讀檔、自動續玩與備份功能；實際能力依核心與遊戲而異。

> **本 App 不附帶遊戲 ROM 或商業主機 BIOS，也不提供下載連結。** ROM 與必要的 BIOS 請由使用者自行準備，並確認具有使用權限。GenieBox 提供遊戲庫介面與內嵌模擬功能。

### 裝置需求與目前狀態

- Android 8.0（API 26）以上，系統必須支援 `arm64-v8a` 64 位元 App。
- TV 主要適配目標：Amlogic S905X5M Android TV Box；手機支援觸控與外接手把。
- 手機與 TV 介面以清楚導航、快速選遊戲及流暢操作為設計目標。實際流暢度與遊戲速度依裝置、散熱、核心、遊戲及渲染設定而異。
- 目前為開發中版本。已整合六個模擬核心，涵蓋下列平台；不代表全部遊戲或 S905X5M 實機相容性已完成驗證。PSP 尤其需要逐款實測，不保證所有遊戲滿速。

### 第一次使用

1. 安裝適合裝置的 APK，準備自己的 ROM；需要 BIOS 的平台另行準備對應檔案。
2. 品牌開場結束後進入遊戲庫；可點擊畫面或按手把按鈕跳過。尚無遊戲時，使用「新增遊戲資料夾」，或從「設定 → 遊戲資料夾」新增手機、USB 或 SD 卡目錄並授予存取權限。
3. 掃描完成後，從遊戲庫選擇遊戲。手機使用虛擬手把，TV 可搭配 USB、藍牙或 2.4 GHz 接收器手把。
4. 遊戲中點擊暫停圖示，或按返回鍵開啟選單；選擇「儲存並返回遊戲庫」即可換遊戲。

開場為 8-bit 神燈、煙霧聚合成 GenieBox 圖示的品牌動畫，不需要帳號登入。「設定 → 語言與外觀 → 開場動畫」提供每次播放、每日首次播放與關閉。

### 遊戲中操作

- **遊戲速度**：在「暫停選單 → 遊戲設定」選擇 1×、1.25×、1.5×、1.75×、2× 或 3×，每款遊戲分別記住倍率。倍率為目標速度，不保證裝置或所有遊戲都能達到。
- **加速聲音**：同一選單提供「加速時靜音」開關，預設開啟並記住選擇。關閉後保留聲音，音效會隨加速變快、音調變高，未提供維持原音調的處理。
- **存檔槽資訊**：在「暫停選單 → 存讀檔」中，手動槽 1–5 以卡片標示「空槽／已存檔／版本不相容」及日期時間，並顯示目前選中的槽位；有預覽的槽位會顯示縮圖，選中後可查看較大的截圖。空槽與版本不相容的槽位停用讀檔。
- **操作確認**：暫停選單的繼續、儲存並返回、重新開始及不儲存離開會直接執行，不再跳第二次確認；「不儲存並離開」會放棄尚未保存的進度。從存讀檔區覆蓋已有的手動槽仍會詢問。
- **存檔截圖**：新存檔會嘗試擷取遊戲畫面；舊存檔需再次儲存才會建立預覽。若擷取失敗，仍可儲存遊戲進度，截圖不是存檔成功的必要條件。
- **接續遊戲**：以「儲存並返回遊戲庫」離開時更新獨立的自動存檔。遊戲庫有可用的相容自動存檔時，提供「繼續」入口直接載入；一般選取遊戲時仍可詢問接續或重新開始，可在「設定 → 存檔備份」關閉接續詢問。重新開始仍保留遊戲原生 SRAM／記憶卡。
- **快速存讀**：使用手動槽 1；手把 SELECT＋R 快存、SELECT＋L 快讀，鍵盤 F5 快存、F8 快讀。快存直接覆寫槽 1 並保留上一份備份。遊戲畫面不顯示額外的快存／快讀浮條，觸控存讀檔從暫停選單操作。
- **上一份手動存檔**：覆寫手動槽時保留舊進度；存在相容備份時，可在存讀檔區查看備份時間並載入上一份。舊版本尚未建立的備份不會自動補生。
- **每款遊戲的畫面設定**：在「暫停選單 → 遊戲設定」調整比例與平滑濾鏡，個別保存；未自訂時沿用全域設定。FC／NES 另有每款遊戲的減少慢動作選項，實際效果與相容性依遊戲而異。
- **倒帶**：FC、GB／GBC、GBA、SFC 可在遊戲設定中開啟，預設關閉。最多保留約 10 秒或 32 MB 歷史；使用選單按鈕、手把 SELECT＋L2 或鍵盤 F6 倒帶約 3 秒。需先累積歷史，重新開始或讀檔後重新累積；會增加 CPU 與記憶體負擔，不支援 PS1／PSP。
- **效能診斷**：FPS HUD 顯示執行速度、平均影格耗時、逾時影格與音訊中斷累計。每款遊戲可選擇落後時減少畫面呈現，仍執行遊戲影格；這不保證滿速，也不能消除原主機本身的慢動作。

截至 2026-10-24，Debug APK 已編譯成功，並在 RMX3850 手機驗證 FC《洛克人 3》的 A 跳躍、B 射擊、橫直向雙指操作、滑鍵與放開／取消後不黏鍵；已修復畫面重組後動作按鍵觸控區域遺失的問題。另已驗證直接續玩、快速存讀、FC 倒帶、自訂名稱與封面、按鍵位置保存、2,000 個合成檔案掃描及掃描取消。存檔故障注入測試確認失敗後主檔、上一份備份及進度中繼資料可還原。

上述結果不代表全平台驗收：多實體手把重連與混合輸入、GB／GBA／SFC 倒帶、PS1／PSP、低階手機、長時間遊玩及 S905X5M 實機仍需擴大測試。其他整合資訊見 [整合狀態](docs/INTEGRATION_STATUS.md)。

## 支援平台與核心

| 平台 ID | 平台名稱 | 模擬核心 | 支援格式 | 多人同玩擴充 |
|---|---|---|---|---|
| nes | 任天堂 NES / FC | FCEUmm | .nes, .zip | 支援 Four Score 4 人同玩 |
| gb | Game Boy / Color | Gambatte | .gb, .gbc, .zip | 單人模式 |
| gba | Game Boy Advance | mGBA | .gba, .zip | 單人模式 |
| sfc | 超任 Super Famicom | Snes9x | .sfc, .smc, .zip | 支援 Multitap 4 人同玩 |
| ps1 | PlayStation 1 | PCSX ReARMed | .cue + .bin, .chd, .m3u | 支援 Multitap 4 人同玩 |
| psp | PlayStation Portable | PPSSPP Libretro | .iso, .cso, .pbp | 原生單人模式 |

「任天堂」在此指 NES／FC；GB 與 GBC 共用核心。當前未整合 N64、NDS、3DS、GameCube、Wii、Switch 或 PS2。

表列格式與多人能力為目前整合範圍，實際可用性需依核心版本與遊戲確認。四人同玩僅適用支援的主機與遊戲；不包含 GB／GBA 通信連線或 PSP 無線對戰。

## ROM 資料夾整理

建議於手機可授權的資料夾、USB 隨身碟或 SD 卡建立以下結構，並在 App 選取 `GenieROMs` 目錄：

```text
GenieROMs/
  nes/      # 放置 .nes 檔案
  gb/       # 放置 .gb, .gbc 檔案
  gba/      # 放置 .gba 檔案
  sfc/      # 放置 .sfc, .smc 檔案
  ps1/      # 放置 .cue + .bin, .chd, .m3u
  psp/      # 放置 .iso, .cso
```

- 同目錄同主檔名之 `.png`、`.jpg`、`.webp` 自動關聯為遊戲封面。
- 遊戲卡片的「⋯」可修改顯示名稱、選擇本機封面或還原原始名稱與封面，不會修改 ROM 檔名。
- NES／FC、GB／GBC、GBA、SFC 可直接選取 ZIP 遊戲；請放在對應平台資料夾，每個 ZIP 只包含一個受支援的 ROM，解壓後上限為 128 MB。PS1／PSP 的 ZIP 不在支援範圍。
- 掃描顯示已辨識數量與目前檔案，可按「停止掃描」；中止掃描不會以不完整結果取代原有索引。重掃沿用未變更的資料與搜尋索引。
- PS1 CUE 參照之 BIN 音軌由掃描器自動過濾，不造成海報牆重複。

## 控制器與 USB Hub 操作

1. **四手把管理**：提供 P1–P4 輸入管理，支援 USB、藍牙與 2.4 GHz 接收器手把。USB Hub 四手把與混接相容性需在目標裝置驗證，依遊戲、接收器、供電與系統而異。
2. **槽位指派**：優先使用手動指派時保存的玩家偏好，否則依可用槽位自動分配 P1–P4。同型號無法區分時，可在設定頁點擊「重新偵測」並按下手把任意鍵加入。
   - 在「設定 → 控制器與觸控」各玩家的「按鍵映射」中，先選擇虛擬按鍵，再按對應玩家手把上的實體按鈕。映射依玩家與手把裝置識別保存，另保留裝置映射供重新分配玩家時沿用，可恢復預設；方向軸維持原設定，遊戲庫導航快捷鍵不受映射影響。
   - 遊戲中收到已指派手把的斷線事件時，會開啟暫停選單並釋放遊戲輸入。重新連接後需手動選擇「繼續遊戲」。
3. **操作按鍵對照**：
   - 【A / 確認】：啟動遊戲
   - 【Y】：切換加入/移除我的收藏
   - 【X】：焦點切換至搜尋欄位
   - 【L1 / R1】：快速切換分類標籤
   - 【Back / 返回鍵】：遊戲中開啟暫停選單 (阻斷遊戲輸入，防止誤觸)

### 手機虛擬手把

- 預設顯示虛擬按鍵；可在「設定 → 控制器與觸控」選擇自動、總是顯示或總是隱藏。
- 可依平台與橫／直向調整透明度、整體大小、邊距、底部位置與震動；「編輯按鍵位置與大小」提供拖曳與個別大小調整。
- 遊戲內的編輯版面依每款遊戲與橫／直向保存；可切回使用平台版面。
- 支援方向鍵與動作鍵同按、A／B 同按，以及按住原動作鍵滑向另一顆鍵。部分手機的系統三指截圖手勢會先攔截觸控，需依手機系統設定處理。

## 存檔與資料安全

- 原生電池存檔 (SRAM / 記憶卡) 存放於內部 `files/saves/<platform>/<game-id>/`。
- 即時存檔存放於 `files/states/<core-id>/<game-id>/`，提供手動 1–5 槽與退出時自動續玩槽 (Slot 0)。
- 存檔預覽 PNG 與即時存檔存放於同一持久目錄，時間與預覽路徑由 Room 中繼資料記錄；自動續玩槽不占用手動槽。
- 即時存檔採暫存寫入、舊檔快照與持久回復日誌，協調主檔、備份及 Room 中繼資料提交；失敗時回復原資料，啟動時也會處理未完成的回復。這可降低寫入中斷風險，仍建議定期匯出備份。
- 手動槽的上一份進度保存在 `.previous`，包含核心與格式版本資訊；版本不相容時不載入。
- 可在設定中一鍵匯出包含存檔與收藏之 ZIP 完整備份。

## 開發者建置指令

設定 Android SDK、NDK 與專案使用的 JDK 後，使用 Gradle 8.7 執行以下指令。目前儲存庫只有 Wrapper 設定，未包含 `gradlew`／`gradlew.bat` 與 Wrapper JAR；請使用已安裝的 Gradle 8.7 或 Android Studio 的 Gradle 執行環境：

```bash
# 1. 編譯六大平台原生 Libretro 核心 (.so 產物將輸出至 app/src/main/jniLibs/arm64-v8a)
bash scripts/build_cores.sh

# 2. 建置 Debug APK (支援 Android 電視盒側載)
gradle :app:assembleDebug

# 3. 執行單元測試
gradle :app:testDebugUnitTest
```

## APK 發布頁介紹文案

以下適用於 GitHub Releases 或 APK 下載頁。APK 是安裝檔格式；若另行發布至應用商店，需依該平台要求準備素材與說明。

### 短介紹

無廣告的開源復古遊戲 App，為 Android 手機與 TV Box 設計。匯入自己的 ROM，用觸控或手把重溫經典。

### 完整介紹

**你的老遊戲，新的收藏方式。**

阿拉丁 GenieBox 將復古遊戲庫與模擬核心整合在同一個 App。無論是在手機上玩一關，還是接上客廳電視與手把，都能從自己的遊戲收藏開始。

- 支援 NES／FC、GB／GBC、GBA、超任 SFC／SNES、PS1 與 PSP。
- 讀取手機資料夾、USB 隨身碟與 SD 卡中的遊戲檔案。
- 手機虛擬手把與直橫向介面，TV 焦點導航與實體手把操作。
- 平台分類、搜尋、收藏與最近遊玩，快速找到想玩的遊戲。
- 本機存檔、即時存讀檔與備份，方便下次接著玩。
- 存檔槽狀態、時間與截圖預覽，支援直接續玩與上一份手動存檔回復。
- 每款遊戲的畫面與觸控版面設定，可自訂遊戲名稱及本機封面。
- FC／GB／GBA／SFC 可選倒帶，實際能力依核心與遊戲而異。
- 最高 3× 目標加速與可選加速靜音，實際速度依裝置與遊戲而異。
- P1–P4 手把按鍵映射與遊戲中斷線暫停。
- 純淨無廣告、無內購、無須登入，開源且可離線使用。
