English

This policy describes how Aladdin GenieBox (com.aladdin.geniebox), maintained by the developer of the zzshcool/aladdin-geniebox project, handles information.

GenieBox is designed for local emulation. It does not require an account, include advertising or analytics SDKs, or automatically upload your game library or progress to a developer-operated server.

1. Information stored on your device

The app stores information needed to provide its features, including:

  • Authorized ROM folder references, filenames, game titles, platform information, cover references, and scan results.
  • Favorites, recent play history, save states, native game saves, and save preview images.
  • Language, appearance, playback, touch control, and controller mapping settings. Controller identifiers may be stored to remember mappings.
  • BIOS files you import and temporary ROM copies needed to run games.

This information is used locally to browse and run games, restore progress, and remember your preferences. The app does not sell this information or use it for advertising or profiling.

2. File access and device features

You select ROM folders and import or export files through Android’s system file picker. The app uses the access you grant to read games and covers, import BIOS files, and read or write backups. It may retain folder access so you do not need to select the same folder each time.

Vibration is used for optional touch feedback. Wake and screen-on features help prevent sleep during use. Compatible controllers provide button and directional input. The app does not request access to contacts, location, the camera, or the microphone.

3. Network access and third parties

The current app is designed to work offline and does not request Android’s INTERNET permission. It does not provide ROM or BIOS downloads, account services, advertising, or developer-operated cloud synchronization.

If you select a cloud-backed document provider in Android’s file picker, that provider may transfer files under its own settings and privacy policy. External websites you choose to visit are also governed by their respective policies.

4. Backups, retention, and deletion

App-managed data generally remains until you remove it, clear app storage, or uninstall the app. Temporary cached files may be cleared separately. Clearing app storage or uninstalling can remove game progress; export a backup first if you want to keep it.

Android system backup is enabled for the app. Depending on your Android version, device manufacturer, and system settings, eligible app data may be included in system-managed cloud backups or device transfers. Those services are controlled by the operating system or backup provider, not a GenieBox server.

ROMs in your selected folders and backups you export remain in their selected locations. Clearing or uninstalling the app does not necessarily delete these external files or existing system backups. Manage those copies through the relevant file manager or backup settings. You can revoke folder access through the system controls available on your device.

5. Information you choose to share

If you submit an issue or support request, the developer can see the information you provide. GitHub issues are public. Do not attach passwords, signing keys, personal files, ROMs, BIOS files, or other sensitive material; review logs and screenshots before sharing.

6. Policy updates and contact

This policy may be updated when the app’s information handling changes. Updates will be posted on this page with a revised date.

For privacy questions, contact the project maintainer through GitHub Issues. This policy page is hosted by GitHub Pages; GitHub’s handling of website visits is covered by the GitHub Privacy Statement.

繁體中文

本政策說明 Aladdin GenieBox／阿拉丁 GenieBox（套件名稱：com.aladdin.geniebox）如何處理資訊。本 App 由 zzshcool/aladdin-geniebox 專案開發者維護。

GenieBox 以本機模擬為主要用途，無須註冊帳號，未整合廣告或分析 SDK，也不會自動將遊戲庫或遊戲進度上傳至開發者營運的伺服器。

1. 儲存在裝置上的資訊

為提供功能，App 會在裝置上保存：

  • 已授權 ROM 資料夾的參照、檔名、遊戲名稱、平台資訊、封面參照與掃描結果。
  • 收藏、最近遊玩紀錄、即時存檔、遊戲原生存檔與存檔預覽圖片。
  • 語言、外觀、播放速度、觸控操作及手把映射設定；為記住映射，可能保存手把識別資訊。
  • 你自行匯入的 BIOS，以及執行遊戲所需的 ROM 暫存副本。

上述資訊用於本機遊戲瀏覽、執行、恢復進度與保存偏好設定，不會販售，也不會用於廣告投放或使用者輪廓分析。

2. 檔案存取與裝置功能

你透過 Android 系統選檔介面選擇 ROM 資料夾、匯入或匯出檔案。App 使用你授予的權限讀取遊戲與封面、匯入 BIOS，以及讀寫備份；可能保留資料夾授權，讓你下次無須重新選取。

震動功能用於可選擇的觸控回饋；喚醒及螢幕常亮功能用於避免使用期間休眠；相容手把提供按鍵與方向輸入。App 不要求存取聯絡人、位置、相機或麥克風。

3. 網路與第三方服務

目前 App 以離線運作為設計方向，未要求 Android 的 INTERNET 網路權限。不提供 ROM 或 BIOS 下載、帳號服務、廣告或開發者營運的雲端同步。

若你在 Android 選檔介面選擇雲端文件服務，該服務可能依其設定與隱私政策傳輸檔案。你自行開啟的外部網站，亦適用各網站的政策。

4. 備份、保存與刪除

App 管理的資料通常會持續保存，直到你移除資料、清除 App 儲存空間或解除安裝；暫存檔可另行清理。清除資料或解除安裝可能刪除遊戲進度，如需保留，請先匯出備份。

本 App 已啟用 Android 系統備份。依 Android 版本、裝置廠商及系統設定，符合條件的 App 資料可能納入系統管理的雲端備份或裝置移轉。這些服務由作業系統或備份供應商管理，並非 GenieBox 伺服器。

你選擇的資料夾內的 ROM，以及自行匯出的備份，會保留在所選位置。清除資料或解除安裝不一定會刪除這些外部檔案或既有系統備份；請透過檔案管理工具及備份設定另行管理。你可使用裝置提供的系統控制項撤銷資料夾存取授權。

5. 你主動提供的資訊

當你提出問題回報或支援請求時，開發者可查看你提供的內容。GitHub Issues 是公開的，請勿上傳密碼、簽章金鑰、個人檔案、ROM、BIOS 或其他敏感資料；分享日誌與截圖前，請先檢查內容。

6. 政策更新與聯絡方式

若 App 的資訊處理方式改變，本政策可能隨之更新；更新內容會公布於本頁，並調整日期。

如有隱私相關問題，請透過 GitHub Issues聯絡專案維護者。本政策頁由 GitHub Pages 託管；GitHub 如何處理網站瀏覽資訊，請參閱 GitHub 隱私權聲明。
